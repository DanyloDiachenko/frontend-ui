UI Controls: Опис та приклади

Лабораторна робота: Дослідження та практична реалізація 10 базових елементів інтерфейсу користувача.

1. Radiobutton 2. Checkbox 3. Text input 4. Tabs 5. Button 6. Text label 7. Link 8. Tooltip 9. Dropdown list 10. Data grid

1. Radiobutton

Призначення: Дозволяє користувачеві вибрати лише один варіант із набору взаємовиключних опцій.
  • Застосовується там, де можлива тільки одна відповідь (наприклад, стать, метод оплати).
  • Об'єднується в одну логічну групу за допомогою однакового атрибута name.

2. Checkbox

Призначення: Дозволяє вибрати одну, декілька або жодної опції, а також підтвердити стан «так/ні».
  • Кожен прапорець працює незалежно від інших у групі.
  • Використовується для погодження з умовами, фільтрації товарів або налаштувань.

3. Text input

Призначення: Забезпечує введення та редагування однорядкового тексту користувачем.
  • Підтримує текстові дані: ім'я, адреса пошти, пароль або пошуковий запит.
  • Містить підказку (placeholder) та обмеження довжини рядка.

4. Tabs

Призначення: Організовують пов'язаний вміст у окремі вкладки для економії місця на сторінці.
  • Дозволяють перемикатися між розділами без перезавантаження сторінки.
  • Відображають лише одну активну панель контенту в певний момент.

5. Button

Призначення: Викликає виконання певної дії при натисканні (відправка, збереження, видалення).
  • Має візуальну ієрархію: головна дія (primary), другорядна (secondary), деструктивна (danger).
  • Змінює вигляд при наведенні курсору та натисканні.

6. Text label

Призначення: Текстовий підпис, який ідентифікує елемент введення або відображає інформаційний статус.
  • Пов'язується з полем форми за допомогою атрибута for для покращення доступності.
  • Служить індикатором стану (успіх, попередження, помилка).

7. Link

Призначення: Навігаційний елемент для переходу на іншу сторінку, зовнішній сайт або розділ документа.
  • Створюється за допомогою тега <a href="...">.
  • Візуально виділяється кольором та підкресленням.

8. Tooltip

Призначення: Спливаюча підказка, яка показує додаткову інформацію при наведенні курсору миші.
  • Забезпечує контекстну довідку без перевантаження інтерфейсу зайвим текстом.
  • Зникає, коли курсор прибирається з елемента.

9. Dropdown list

Призначення: Дозволяє користувачеві вибрати одне значення зі списку варіантів, що розгортається.
  • Економить місце на екрані при наявності великої кількості пунктів вибору.
  • Використовується для вибору країни, мови, сортування тощо.

10. Data grid

Призначення: Структуроване відображення табличних даних у вигляді рядків і стовпців.
  • Використовується для звітів, списків користувачів, каталогів та фінансових таблиць.
  • Забезпечує чітке співставлення властивостей кожного об'єкта.
